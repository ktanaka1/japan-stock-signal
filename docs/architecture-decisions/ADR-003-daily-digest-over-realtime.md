# ADR-003: リアルタイム通知をやめ、朝のデイリーダイジェストにする

## 状況

当初（2026-06-10 稼働開始時）は、5分ごとに新着シグナルを検出して
そのつどLINEへリアルタイム通知する方式だった。

## 選択肢

- **平日朝に1通のデイリーダイジェスト**（前回配信以降のシグナルをまとめる）
- リアルタイム通知（シグナル検出のたびに送る）
- ハイブリッド（重要シグナルのみ即時、残りは朝まとめ）

## 決定

**平日朝7:30のデイリーダイジェスト1通**方式に変更（コミット 265e4ce）。

## 理由

- **LINE無料枠は月200通**。リアルタイム（5分ごと）では容易に超過する。1日1通なら受信者が増えても月21通程度で収まる
- ターゲットがデイトレーダーで、**寄付き前（9:00）の準備時間に「今日見る銘柄」を一覧で受け取る**用途に合致する
- 通知過多による見落とし・通知疲れを避ける

## 補足

- ハイブリッド（TOB・業績修正など影響度最大級のみ場中即時）は将来の拡張候補として保留
- ゼロ件の日も「該当なし」を1通送り、無通知（＝障害）と区別する
